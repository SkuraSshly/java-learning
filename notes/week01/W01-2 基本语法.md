## 一、8 种基本数据类型

为什么区分基本类型：变量里直接存值，不是对象，不在堆上分配，性能好；代价是不能为 null、不能调方法，所以每种基本类型配一个包装类（int ↔ Integer，第 3 周）。每种类型的大小在所有平台上固定，这也是跨平台的一部分。

| 类型 | 大小 | 取值范围 | 默认值 | 字面量 |
|---|---|---|---|---|
| byte | 1 字节 | -128 ~ 127 | 0 | |
| short | 2 字节 | -32768 ~ 32767 | 0 | |
| int | 4 字节 | -2³¹ ~ 2³¹-1（约 ±21 亿） | 0 | `100`、`0x1F`、`0b101`、`1_000_000` |
| long | 8 字节 | -2⁶³ ~ 2⁶³-1 | 0L | `100L`，超出 int 范围必须加 L |
| float | 4 字节 | 约 ±3.4×10³⁸，6~7 位有效数字 | 0.0f | `3.14f`，必须加 f |
| double | 8 字节 | 约 ±1.8×10³⁰⁸，15~16 位有效数字 | 0.0 | 小数默认是 double |
| char | 2 字节 | 0 ~ 65535（无符号，UTF-16） | '\u0000' | `'a'`、`'中'` |
| boolean | 规范未规定 | true / false | false | |

口诀：整型 1、2、4、8，浮点 4、8，char 2，boolean 不定。

- 整数字面量默认 int，小数字面量默认 double：`long l = 2147483648;` 和 `float f = 3.4;` 都编译报错。
- char 是 2 字节，能存中文。boolean 大小规范没规定，取决于 JVM 实现。
- 默认值只对成员变量和数组元素生效，局部变量不赋值就用会编译报错。
- 整数溢出不报错，从最大值绕到最小值：`Integer.MAX_VALUE + 1 == -2147483648`。求中点写 `left + (right - left) / 2`；要检测溢出用 `Math.addExact`。

## 二、类型转换与精度丢失

- 自动转换（小 → 大）：byte → short → int → long → float → double，char → int。
- long / int 自动转 float 会丢精度：float 只有 24 位有效二进制位，`(int)(float)16777217 == 16777216`。
- 强制转换（大 → 小）必须写 `(类型)`：`(int)3.9 == 3`（截断，不是四舍五入），`(int)-3.9 == -3`，`(byte)200 == -56`（只留低 8 位，按补码 200-256）。
- 表达式提升：byte / short / char 参与运算先提升为 int。`short s = 1; s = s + 1;` 编译错误；`s += 1;` 正确，因为复合赋值自带强转。
- 常量在范围内可以直接赋给 byte：`byte b = 127;` 可以，`byte b = 128;` 不行。
- 浮点精度：`0.1 + 0.2 == 0.30000000000000004`，二进制无法精确表示 0.1。浮点数比较用 `Math.abs(a - b) < 1e-9`；金额用 BigDecimal 或 long 存「分」。
- 整数除法截断：`1 / 2 == 0`。取余符号跟被除数：`-7 % 3 == -1`（Python 是 2），判断奇数写 `n % 2 != 0`。

## 三、运算符

- `i++` 先用后加，`++i` 先加后用。`i = i++` 之后 i 不变；`int a = 5; int b = a++ + ++a;` 结果 a=7、b=12。
- `&&` / `||` 短路，`&` / `|` 两边都算，还能做按位运算。常用 `s != null && s.length() > 0` 判空。
- 位运算：`&` 与、`|` 或、`^` 异或、`~` 取反、`<<` 左移（×2ⁿ）、`>>` 有符号右移（补符号位）、`>>>` 无符号右移（补 0，Java 特有）。
- 技巧：`(n & 1) == 0` 判偶数；`n > 0 && (n & (n-1)) == 0` 判 2 的幂；`a ^ a == 0`；n 是 2 的幂时 `x & (n-1) == x % n`（HashMap 求下标）；`1 << 40` 对 int 是 256，要写 `1L << 40`。
- 三元运算符两个分支类型不同会统一提升：`Object o = true ? 1 : 2.0;` 打印 1.0。
- char 运算：`'a' + 1 == 98`，`(char)('a' + 1) == 'b'`，`"" + 'a' + 1` 是 "a1"，刷题用 `c - 'a'` 做计数数组下标。
- `Math.round` 向正无穷舍入（floor(x + 0.5)）：`Math.round(-1.5) == -1`，`Math.round(-2.5) == -2`。

## 四、流程控制

- 条件必须是 boolean，`if (1)` 编译不过；代码块靠 `{}`。
- 增强 for `for (int v : arr)` 拿不到下标，也不能遍历时删集合元素。`do-while` 至少执行一次。
- 传统 switch 没有 break 会穿透（fall-through）。新式 `->` 不穿透，可以作为表达式返回值，多个值用逗号，代码块里用 `yield` 返回；作为表达式时必须覆盖所有情况。
- switch 支持 byte / short / char / int 及包装类、String（JDK 7）、enum；不支持 long / float / double / boolean。JDK 21 起支持模式匹配（`case Integer i ->`）。
- 带标签的 break / continue 能跳出多层循环：`outer: for (...) { for (...) { break outer; } }`。

## 五、面试常怎么问

1. 8 种基本类型各占几个字节？→ 1、2、4、8 / 4、8 / char 2 / boolean 不定。
2. `short s = 1; s = s + 1;` 和 `s += 1;` 的区别？→ 前者编译错误，后者复合赋值自带强转。
3. `float f = 3.4;` 对吗？→ 不对，要写 3.4f。
4. `0.1 + 0.2 == 0.3` 吗？金额用什么？→ 不等；BigDecimal。
5. `&` 和 `&&` 的区别？→ 短路；& 还能按位与。
6. `>>` 和 `>>>` 的区别？→ 补符号位 vs 补 0。
7. `Math.round(-1.5)`？→ -1。
8. switch 能用在 long / String 上吗？→ long 不行，String 从 JDK 7 起可以。
9. `i = i++` 之后 i 是多少？→ 不变。
10. 如何跳出多重循环？→ 带标签的 break，或抽成方法 return。

## 六、自测题与答案

1. `byte a = 10, b = 20; byte c = a + b;` → 编译错误。a + b 先提升为 int，赋给 byte 要强转：`(byte)(a + b)`。对比：`byte c = 10 + 20;` 可以，因为两边都是常量，编译期算出 30 在范围内。
2. `long x = Integer.MAX_VALUE * 2;` → x 是 -2。两个 int 先相乘按 int 溢出，之后才赋给 long。改成 `Integer.MAX_VALUE * 2L`，结果 4294967294。
3. 传统 switch，x = 3，case 3/4/default 都没 break → 输出 ABC（穿透）。改成新式 `->` 只输出 A。
