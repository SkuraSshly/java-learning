## 一、数组基础

**数组是什么**：一块连续的内存，存放相同类型的元素。

**为什么下标从 0 开始、随机访问是 O(1)**：第 i 个元素的地址 = 起始地址 + i × 元素大小，一次乘法加法就能算出来，不用从头找。下标从 0 开始，这个公式里就不用减 1。

**为什么长度固定**：创建时一次性申请好连续内存，后面的内存可能已经被别人占了，没法原地变长。要「扩容」只能建一个更大的新数组再复制过去，ArrayList 就是这么做的（第 5 周）。

```java
int[] a = new int[3];           // 指定长度，元素是默认值
int[] b = {1, 2, 3};            // 静态初始化，只能在声明时这样写
int[] c = new int[]{4, 5, 6};   // 可以先声明、后赋值
// int[] d = new int[3]{1, 2, 3};   ❌ 指定了长度就不能再给初始值
```

- `arr.length` 是字段，不加括号。对比：String 是 `s.length()` 方法，集合是 `list.size()`。
- 默认值和成员变量一样：整数 0、浮点 0.0、boolean false、char `'\u0000'`、引用类型 null。
- 越界抛 `ArrayIndexOutOfBoundsException`，是运行时异常，编译器查不出来。
- 直接 `println(arr)` 打印的是 `[I@7e9e5f8a`（`[I` 表示 int 数组，后面是哈希码），要看内容用 `Arrays.toString(arr)`。

**数组是对象**：数组在堆上，变量里存的只是地址。

```java
int[] b = {1, 2, 3};
int[] alias = b;        // 没有复制数组，只复制了地址
alias[0] = 100;         // b[0] 也变成 100
int[] copy = b.clone(); // 这才是复制一份新数组
```

- `==` 比较的是地址，判断是不是同一个数组。
- 增强 for 里的变量是元素的副本：`for (int v : arr) v = 0;` 不会改数组。要改元素，用下标。
- 空数组 `new int[0]` 和 `null` 不一样：前者 length 是 0，后者取 length 会抛 NullPointerException。方法返回「没有结果」时，返回空数组比返回 null 更安全。

## 二、二维数组

Java 的二维数组是**数组的数组**：外层数组的每个元素，是一个一维数组的地址。所以它在内存里不一定连续（C 语言的二维数组是连续的）。

```
grid ──▶ [ 0x10, 0x20 ]
            │     └──▶ [4, 5, 6]
            └────────▶ [1, 2, 3]
```

- `m.length` 是行数，`m[i].length` 是第 i 行的列数。
- `new int[3][]` 只建了外层，每行是 null，可以给每行不同的长度（锯齿数组）。`new int[][3]` 编译报错，必须先指定第一维。
- 打印用 `Arrays.deepToString`；`Arrays.toString` 只会打出每一行的地址。
- `grid.clone()` 是**浅拷贝**：只复制了外层的地址，两个二维数组共享同一批行。深拷贝要逐行 clone。

## 三、Arrays 工具类

都是 `java.util.Arrays` 里的 static 方法，要 `import java.util.Arrays;`。

| 方法 | 作用 | 注意 |
|---|---|---|
| `toString(arr)` / `deepToString(arr)` | 打印一维 / 多维数组 | |
| `sort(arr)` / `sort(arr, from, to)` | 原地升序排序，返回 void | 区间是左闭右开 `[from, to)` |
| `sort(arr, Comparator)` | 自定义顺序 | 只能用于对象数组：降序要用 `Integer[]` 配合 `Collections.reverseOrder()` |
| `fill(arr, val)` | 全部填成同一个值 | 刷题初始化 dp 数组常用 |
| `copyOf(arr, newLen)` | 复制成新长度的新数组 | 变长补默认值，变短截断 |
| `copyOfRange(arr, from, to)` | 复制一段 | `[from, to)` |
| `equals(a, b)` / `deepEquals(a, b)` | 比较内容 | `a.equals(b)` 没被重写，等于 `==` |
| `binarySearch(arr, key)` | 二分查找 | 数组必须有序；找不到返回 `-(插入点) - 1` |
| `asList(...)` | 转成 List | 长度固定不能增删；基本类型数组会被当成一个元素 |

- `Arrays.sort` 的算法：基本类型数组用**双轴快速排序**（Dual-Pivot Quicksort，不稳定，相同值本来就分不出先后，稳不稳定无所谓）；对象数组用 **TimSort**（归并 + 插入排序，稳定，保证相等对象的原有顺序不变）。
- `System.arraycopy(src, srcPos, dest, destPos, length)` 是 native 方法，`Arrays.copyOf` 底层就是调它。
- 复制数组的四种方式：for 循环、`clone()`、`System.arraycopy`、`Arrays.copyOf`。对引用类型数组，它们都是浅拷贝。

## 四、方法

```java
修饰符    返回类型  方法名(参数列表) {
static    int       max(int a, int b) {
    return a > b ? a : b;
}
```

- `void` 方法没有返回值，也可以用 `return;` 提前结束。非 void 方法的每条路径都必须 return。
- main 是 static，所以 main 里能直接调用的是 static 方法；不带 static 的方法属于对象，要先 new 对象（第 2 周）。
- **方法签名 = 方法名 + 参数列表**（参数的个数、类型、顺序），不包括返回值和参数名。

### 重载（Overload）

同一个类里，方法名相同、参数列表不同。

- **只有返回值不同不算重载**，编译报错 `already defined`。原因：调用 `add(1, 2)` 时如果不用返回值，编译器无法判断该调哪个。
- 调用时编译器按以下优先级选方法：**精确匹配 > 基本类型拓宽（int → long → double）> 自动装箱（int → Integer）> 可变参数**。
  - 有 `show(int)` 时 `show(5)` 选它；只有 `pick(long)` 和 `pick(Integer)` 时，`pick(5)` 选 long。
  - 有 `total(int, int)` 和 `total(int...)` 时，`total(1, 2)` 选固定参数版。
- 为什么这样设计：拓宽和装箱是 JDK 5 之前和之后的规则，先拓宽是为了老代码升级 JDK 后调用的方法不变。

**重载 vs 重写**（重写第 2 周讲，先记一句）：重载是同一个类里同名不同参，编译期就决定调哪个；重写是子类重新实现父类的同名同参方法，运行时根据对象的实际类型决定调哪个。

### 可变参数

```java
static int sum(int... nums) { ... }   // nums 就是 int[]
sum();               // 传 0 个，nums 是空数组，不是 null
sum(1, 2, 3);
sum(new int[]{4, 5});    // 也可以直接传数组
```

- 本质是数组，编译器把实参打包成数组再传进去。所以 `f(int...)` 和 `f(int[])` 不能同时存在，签名相同。
- 必须是最后一个参数，一个方法只能有一个。
- 重载时优先级最低，能匹配固定参数的方法就不会选它。
- 常见用法：`String.format("%d-%s", 1, "a")`、`String.join("-", "a", "b")`、`Arrays.asList(1, 2, 3)`。

## 五、Java 只有值传递

**结论**：调用方法时，形参拿到的是实参的**副本**。基本类型复制的是值；引用类型复制的是**地址**。Java 没有 C++ 那种「传引用」（`void f(int& x)`）。

```
        栈                              堆
   main:   arr  = 0x100 ─────┐
                             ▼
                     0x100: [1, 2, 3]
                             ▲
   modify: nums = 0x100 ─────┘     nums 是 arr 的副本，地址相同
```

| 方法里做了什么 | 外面受影响吗 | 原因 |
|---|---|---|
| 改基本类型参数 `x = 100` | 不受影响 | 改的是副本 |
| `swap(int a, int b)` | 交换失败 | 交换的是两个副本 |
| 改数组元素 `nums[0] = 100` | **受影响** | 顺着同一个地址改了堆里的数组 |
| 形参指向新数组 `nums = new int[]{...}` | 不受影响 | 只改了副本里存的地址，外面的变量还是旧地址 |
| `swap(int[] a, int i, int j)` | 交换成功 | 改的是堆里的数组 |
| String 参数 `s = s + "!"` | 不受影响 | String 不可变，`+` 生成新对象，相当于让形参指向新对象（第 3 周细讲） |
| `StringBuilder.append` | **受影响** | 可变对象，改的是同一个对象 |

判断方法：方法里是**通过地址改对象内容**（会影响外面），还是**让形参指向别的对象**（不影响外面）。

想让方法「改」外面的基本类型变量，就用返回值：`n = increase(n);`。要返回多个值，可以返回数组或对象。

## 六、面试常怎么问

1. **数组和 ArrayList 的区别？** → 数组长度固定，ArrayList 自动扩容（底层也是数组，1.5 倍扩容）；数组能存基本类型，ArrayList 只能存对象（int 要装箱成 Integer）；数组用 `length`，ArrayList 用 `size()`；ArrayList 提供 add、remove 等方法。
2. **数组的默认值？** → 整数 0、浮点 0.0、boolean false、char `'\u0000'`、引用类型 null。
3. **`length`、`length()`、`size()` 分别是谁的？** → 数组的字段、String 的方法、集合的方法。
4. **`Arrays.sort` 用的什么排序？** → 基本类型用双轴快排（不稳定）；对象用 TimSort（稳定）。
5. **`==`、`arr.equals()`、`Arrays.equals()` 的区别？** → 前两个都是比较地址（数组没重写 equals）；`Arrays.equals` 比较内容，多维用 `deepEquals`。
6. **重载和重写的区别？** → 重载：同类、同名、参数列表不同，与返回值无关，编译期确定。重写：子类、同名同参，返回值相同或是其子类，访问权限不能更严格，运行时确定（第 2 周详讲）。
7. **只有返回值不同能重载吗？** → 不能，调用时编译器无法区分。
8. **可变参数的原理？** → 编译器把实参打包成数组，方法里拿到的就是数组；必须放最后、只能有一个、重载匹配时优先级最低。
9. **Java 是值传递还是引用传递？** → 只有值传递。引用类型传的是地址的副本，所以能通过它改对象内容，但让形参指向新对象不会影响实参。
10. **为什么 `swap(int a, int b)` 交换不了？** → a、b 是实参的副本，交换的是副本。要交换就放进数组交换元素，或者用返回值。
11. **`Arrays.asList` 有什么坑？** → 返回的列表长度固定，add / remove 抛 UnsupportedOperationException；和原数组共用内存；传 `int[]` 得到的是只有一个元素的 `List<int[]>`。
12. **二维数组在内存里是连续的吗？** → 不一定，它是数组的数组，每一行是单独的对象，所以每行长度可以不同。

## 七、自测题与答案

**1.** 输出什么？

```java
int[] a = {1, 2, 3};
int[] b = a;
b = new int[]{4, 5, 6};
b[0] = 9;
System.out.println(a[0]);
```

<details><summary>答案</summary>

`1`。`int[] b = a` 之后 b 和 a 指向同一个数组，但下一行 `b = new int[]{...}` 让 b 指向了新数组，之后改 `b[0]` 改的是新数组，a 指向的还是原来的 `{1, 2, 3}`。和第五节「形参指向新数组」是同一个道理。

</details>

**2.** 下面两个方法能写在同一个类里吗？

```java
static void f(int... x) { }
static void f(int[] x) { }
```

<details><summary>答案</summary>

不能，编译报错 `cannot declare both f(int[]) and f(int...)`。可变参数编译后就是 `int[]`，两个方法的签名完全一样。

</details>

**3.** 输出什么？

```java
static void f(String s, StringBuilder sb) {
    s += "b";
    sb.append("b");
    sb = new StringBuilder("x");
    sb.append("c");
}

String s = "a";
StringBuilder sb = new StringBuilder("a");
f(s, sb);
System.out.println(s + " " + sb);
```

<details><summary>答案</summary>

`a ab`。
- `s += "b"`：String 不可变，生成新对象 "ab" 赋给形参 s，外面的 s 还是 "a"。
- `sb.append("b")`：通过地址改了外面那个 StringBuilder，变成 "ab"。
- `sb = new StringBuilder("x")`：形参指向新对象，之后的 `append("c")` 改的是新对象，外面看不到。

</details>
