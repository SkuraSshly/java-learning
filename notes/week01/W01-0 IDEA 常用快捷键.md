# 第 1 周 · IDEA 常用快捷键（macOS）

先记住最常用的 10 个，其余用到再查。按 `⌘,` 打开设置 → Keymap，确认右上角选的是 **macOS**，本文都按这套键位写。

符号对照：`⌘` Command，`⌥` Option，`⌃` Control，`⇧` Shift，`⌫` Delete，`↩` Return。

> Mac 键盘上 F1~F12 默认是亮度、音量。用带 F 键的快捷键要同时按 `fn`，或者在「系统设置 → 键盘 → 键盘快捷键 → 功能键」里打开「将 F1、F2 等键用作标准功能键」。

## 零、最常用的 10 个

| 快捷键 | 作用 |
|---|---|
| `⇧⇧`（连按两下 Shift） | 全局搜索：类、文件、设置、操作都能搜 |
| `⌘⇧A` | 搜索操作：忘了快捷键就按它，输入操作名，比如 reformat |
| `⌥↩` | 万能修复：报红、黄色警告时按它，自动导包、补方法、改类型 |
| `⌃R` | 运行上次的程序 |
| `⌃⇧R` | 运行光标所在的 main 方法或测试 |
| `⌘N` | 生成代码：构造方法、getter / setter、toString、equals / hashCode |
| `⌥⌘L` | 格式化代码 |
| `⌘/` | 注释 / 取消注释当前行 |
| `⌘D` | 复制当前行 |
| `⌘B` 或 `⌘` 加点击 | 跳到定义处，看 JDK 源码就靠它 |

## 一、代码模板（不是快捷键，但最省时间）

在编辑器里输入缩写，按 `Tab` 或 `↩` 展开。

| 输入 | 展开成 |
|---|---|
| `psvm` 或 `main` | `public static void main(String[] args) { }` |
| `sout` | `System.out.println();` |
| `soutv` | 打印最近的变量：`System.out.println("x = " + x);` |
| `souf` | `System.out.printf("");` |
| `fori` | `for (int i = 0; i < ; i++) { }` |
| `iter` | 增强 for：`for (Type item : items) { }` |

后缀补全：在表达式后面打点，再输模板名。

| 写法 | 结果 |
|---|---|
| `arr.fori` | `for (int i = 0; i < arr.length; i++) { }` |
| `arr.for` | `for (int v : arr) { }` |
| `x.sout` | `System.out.println(x);` |
| `new ArrayList<>().var` | `ArrayList<Object> list = new ArrayList<>();`，自动生成变量 |
| `s.nn` | `if (s != null) { }` |
| `flag.if` | `if (flag) { }` |

`⌘J` 能看到当前位置可用的全部模板。

> 刷题和面试手写时没有这些帮你补，`public static void main(String[] args)`、`System.out.println` 自己要能一字不差敲出来。

## 二、编辑

| 快捷键 | 作用 |
|---|---|
| `⌃Space` | 代码补全（一般打字时自动弹出） |
| `⌘P` | 显示方法参数提示，光标在括号里时用 |
| `F1` | 查看光标处类 / 方法的文档 |
| `⌘⇧↩` | 补全当前语句：自动补分号、括号、大括号 |
| `⌘D` | 复制当前行（或选中内容） |
| `⌘⌫` | 删除当前行 |
| `⌥⇧↑` / `⌥⇧↓` | 当前行上移 / 下移 |
| `⌘⇧↑` / `⌘⇧↓` | 整条语句或整个方法上移 / 下移 |
| `⌥↑` / `⌥↓` | 扩大 / 缩小选中范围：单词 → 表达式 → 整行 → 代码块 |
| `⌃G` | 选中下一个相同的词，多光标同时改；`⌃⌘G` 选中全部 |
| 按住 `⌥` 拖动 | 列选择 / 多光标 |
| `⌘/` | 行注释 |
| `⌥⌘/` | 块注释 `/* */` |
| `⌥⌘T` | 用 if / for / try-catch 等包住选中代码 |
| `⌥⌘L` | 格式化代码 |
| `⌃⌥O` | 删掉没用的 import |
| `⌘Z` / `⌘⇧Z` | 撤销 / 重做 |
| `⌘-` / `⌘+` | 折叠 / 展开代码块 |

## 三、生成代码

| 快捷键 | 作用 |
|---|---|
| `⌘N` | 生成构造方法、getter / setter、toString、equals / hashCode；在项目窗口里按是新建文件 |
| `⌃O` | 重写父类方法（Override） |
| `⌃I` | 实现接口方法（Implement） |

## 四、查找与跳转

| 快捷键 | 作用 |
|---|---|
| `⇧⇧` | 全局搜索 |
| `⌘O` | 按类名找类，包括 JDK 里的类，比如输入 `HashMap` |
| `⌘⇧O` | 按文件名找文件 |
| `⌥⌘O` | 按方法 / 字段名找 |
| `⌘E` | 最近打开的文件 |
| `⌘F` / `⌘R` | 当前文件查找 / 替换 |
| `⌘⇧F` / `⌘⇧R` | 整个项目查找 / 替换 |
| `⌘B` 或 `⌘` 加点击 | 跳到定义 |
| `⌥⌘B` | 跳到实现类（接口方法上用） |
| `⌥F7` | 查找哪里用到了它 |
| `⌘F12` | 当前文件结构：列出所有方法、字段 |
| `⌃H` | 类的继承层次 |
| `⌘[` / `⌘]` | 后退 / 前进到上一个光标位置，跳进源码后用它跳回来 |
| `⌘L` | 跳到指定行 |
| `F2` / `⇧F2` | 跳到下一个 / 上一个错误 |

> 学集合、多线程时会经常 `⌘O` 输入 `HashMap` 或 `ArrayList` 打开 JDK 源码，再用 `⌘F12` 看它有哪些方法。

## 五、重构

| 快捷键 | 作用 |
|---|---|
| `⇧F6` | 重命名：类、方法、变量，所有引用一起改。改类名会同时改文件名 |
| `⌥⌘V` | 把表达式提取成变量 |
| `⌥⌘M` | 把选中代码提取成方法 |
| `⌥⌘F` / `⌥⌘C` | 提取成字段 / 常量 |
| `⌥⌘N` | 内联（提取的反操作） |
| `⌃T` | 重构菜单，所有重构操作都在这里 |

> 这周把 `Hello` 改名成 `L01_Hello` 这种事，在 IDEA 里就是在类名上按 `⇧F6`。直接在 Finder 里改文件名，类名不会跟着改，会编译报错。

## 六、运行与调试

| 快捷键 | 作用 |
|---|---|
| `⌃⇧R` | 运行光标所在的 main / 测试 |
| `⌃R` | 重新运行上一次的配置 |
| `⌃⇧D` / `⌃D` | 调试光标所在的 main / 调试上一次的配置 |
| `⌘F2` | 停止运行 |
| `⌘F8` | 在当前行加 / 删断点（也可以点行号右边的空白处） |
| `F8` | 单步，不进入方法（Step Over） |
| `F7` | 单步，进入方法（Step Into） |
| `⇧F8` | 跳出当前方法（Step Out） |
| `⌥F9` | 运行到光标所在行 |
| `⌥⌘R` | 继续运行到下一个断点 |
| `⌥F8` | 调试时计算任意表达式 |

> 调试比 `System.out.println` 更好用：加个断点，`⌃⇧D` 启动，一步一步 `F8`，在 Variables 面板里看每个变量的值。用 `L04_Operators` 里的 `int b = a++ + ++a;` 试一下，观察 a 每一步的变化。

## 练习

1. 新建 `L00_Shortcuts.java`（`⌘N` → Java Class），用 `psvm` 生成 main，用 `sout` 打印一句话，`⌃⇧R` 运行。
2. 在 main 里输入 `int[] arr = {3, 1, 4};`，下一行用 `arr.fori` 生成循环，在循环里用 `sout` 打印 `arr[i]`。
3. 把某一行用 `⌘D` 复制两次，`⌥⇧↑` 移动顺序，再 `⌘⌫` 删掉。故意把缩进弄乱，`⌥⌘L` 格式化。
4. 在 `String` 上按 `⌘B` 跳进 JDK 源码，`⌘F12` 看它有哪些方法，`⌘[` 跳回来。
5. 在 `L04_Operators` 的 `int b = a++ + ++a;` 那行 `⌘F8` 加断点，`⌃⇧D` 调试，`F8` 单步，看 a、b 的值。
6. 用完删掉 `L00_Shortcuts.java`（项目窗口里选中按 `⌘⌫`），或者留着当草稿。
